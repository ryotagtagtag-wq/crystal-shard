# Crystal Shard

Crystal Shardは、任意のITアプリケーションに組み込める汎用ポイント・クレジットシステムです。
Next.js 14 (App Router) と Vercel を使用したフルスタックアプリケーションとして実装され、
アプリケーション開発者が安全にポイントシステムを統合できるように設計されています。

## 主な特徴

- **シンプルな統合**: アプリケーションのバックエンドから安全にAPIを呼び出すだけでポイント管理が可能
- **高度なセキュリティ**: アプリケーションシークレットは決してクライアントに露出せず、HMAC-SHA256署名によるリクエスト正当性検証を実装
- **柔軟なボーナスシステム**: デイリーログインボーナス、達成ボーナス、紹介ボーナスなどを標準装備
- **管理ダッシュボード**: アプリケーション統計、信頼スコア管理、不正検知機能を提供
- **エンドユーザーダッシュボード**: ポイント残高確認・取引履歴・ボーナス状況を表示
- **Vercel無料枠対応**: クレジットカード不要で無料プラン内での実装が可能

## アーキテクチャ

アプリケーションクライアント 
    │
    ▼
あなたのアプリケーションバックエンド ← ここでapplicationSecretを環境変数で管理
    │  (例: あなたのアプリのNext.js API route, Cloudflare Worker, 等)
    ▼
Crystal Shard (Vercel Next.js App)

## 重要なセキュリティ注意点

> ⚠️ **絶対にアプリケーションシークレットをクライアントサイドに露出させてはなりません**
> 
> - アプリケーションシークレットはサーバーサイド（あなたのアプリケーションバックエンドまたはプロキシー）でのみ管理してください
> - Next.jsのAPIルートやサーバーコンポーネント内でのみ使用可能
> - クライアントサイドJavaScript、HTML、モバイルアプリに埋め込むことは厳禁
> - 本シークレットがクライアントに漏れると、誰でもポイントを不正に付与・消費できるようになります

## 始め方

1. このリポジトリをクローンまたはフォークしてください
2. `npm install` で依存関係をインストール
3. Vercelプロジェクトを作成し、以下の環境変数を設定：
   DATABASE_URL=postgresql://...          # Vercel Postgres
   NEXTAUTH_SECRET=...                    # NextAuth.js
   APPLICATION_SECRET_MASTER_KEY=...      # 32バイト hex string (アプリケーションシークレット復号用)
   FIREBASE_CLIENT_ID=...                 # Firebase (オプション)
   FIREBASE_CLIENT_SECRET=...             # Firebase (オプション)
4. `npm run dev` で開発サーバーを起動
5. ブラウザで `http://localhost:3000` にアクセス
